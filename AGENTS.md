# AGENTS.md — правила работы с Penguin

Читать перед первой правкой. Для людей и для ИИ-агентов.

`vendor/rust-ui-kit` — чужой крейт со своим `AGENTS.md`. Правишь его — читай тот.

---

## 1. Направление зависимостей

Стрелки идут только вниз. Обратных нет ни одной.

| Крейт | Может зависеть от |
|---|---|
| `core` | ничего внутреннего |
| `config`, `proto`, `match`, `process`, `tun`, `platform` | `core` |
| `netstack` | `core`, `tun` |
| `dns` | `core`, `proto` |
| `inbound` | `core` |
| `router` | `core`, `match`, `config`, `process` |
| `engine` | всё выше + `protocols/*` |
| `ipc` | `core`, `config` |
| `daemon` | `engine`, `ipc`, `config`, `platform` |
| `cli` | `ipc`, `engine`, `inbound`, `proto`, `tun`, `platform` |
| `gui` | `ipc`, `config`, `core`, `platform`, `uikit` |
| `app` | `daemon`, `cli`, `gui`, `config`, `platform` |
| `protocols/transport`, `protocols/utls` | `core`, `proto` |
| `protocols/*` | **только** `core`, `proto`, `transport`, `utls` |
| `servers/*` | `core`, `proto` и свой `protocols/<имя>` |

- **1.1.** Крейт из `crates/` в зависимостях протокола — протокол начал знать
  про клиент. Такая правка отклоняется.
- **1.1.1.** `transport` и `utls` стоят **на уровне протоколов**: зависят от
  того же, о клиенте знают столько же. Запрет 1.1 на них распространяется.
- **1.2.** Нужна стрелка вверх — опусти общий кусок вниз, в `core`.
- **1.3.** `app` — единственный исполняемый крейт. `daemon`, `cli`, `gui` —
  библиотеки и друг о друге не знают. Окну нужна служба — оно запускает
  **себя же** с нужной командой через `platform::run_elevated`.
- **1.4.** `tun` и `platform` у `cli` — только ради `doctor`: он отвечает на
  «почему не работает», а ответ — состояние системы, а не своя копия кода.
- **1.5.** `platform` у `gui` — автозапуск (ветка реестра пользователя, у
  службы её нет), запрос прав и окно выбора файла. Остальное — через `ipc`.
- **1.6.** `servers/*` — отдельные программы для другой машины. Формат провода
  берут из своего `protocols/*`, а не повторяют. Клиент о серверах не знает.

## 2. Размер файла

| Размер | Форма |
|---|---|
| до ~150 строк, одна ответственность | один файл `<name>.rs` |
| несколько связанных сущностей | папка `<name>/` + `mod.rs` + файл на сущность |
| разбор и сборка формата | файл на формат (`frame/tcp.rs`, `frame/udp.rs`) |

- **2.1.** В `mod.rs` — только модули, `pub use` и документ раздела. Логики нет.
- **2.2.** `match` длиннее пары строк — в свободную функцию рядом: её можно
  протестировать отдельно.
- **2.3.** Чистая логика живёт в файлах без `tokio`, `iced` и системных
  вызовов. Такой файл тестируется без сети, прав и ожидания.

## 3. Что где не должно появляться

| Крейт | Чего в нём быть не должно |
|---|---|
| `core` | ввода-вывода, `tokio`, платформенных вызовов |
| `match` | сети, файлов, системных вызовов |
| `protocols/*` | `std::net`, `tokio::net` — сокеты выдаёт `proto::Dialer` |
| `gui` | сетевых вызовов мимо `ipc`, работы с TUN и маршрутами |
| `vendor/rust-ui-kit` | доменных слов: «тоннель», «профиль», «Hysteria» |

- **3.1.** Виджет обобщают, вырезав домен: `Sparkline` уехал в кит, кнопка
  подключения осталась в `gui/src/components/`.
- **3.2.** Виджет заводится в ките, только когда собрать нужное из имеющихся
  **нельзя**. Кит подключён к четырём проектам.

---

## 4. Ошибки

- **4.1.** У каждого крейта своё перечисление через `thiserror`. `anyhow` —
  только в исполняемых крейтах.
- **4.2.** «Повторять / не повторять» — вариант перечисления, а не текст
  сообщения: по нему решает `supervisor`.
- **4.3.** `unwrap` и `expect` на пути соединения запрещены: паника в задаче
  обрывает соединение, а то и тоннель.

---

## 5. Безопасность

- **5.1.** Всё, что демон делает по запросу из канала управления, доступно
  тому, кто до канала дотянулся. Дескриптор безопасности — не формальность.
- **5.2.** Пароли и ключи не попадают в журнал — ни целиком, ни первыми
  четырьмя символами. В `Debug` таких полей заглушка.
- **5.3.** Проверка сертификата выключается только явным полем настроек, и
  интерфейс обязан сказать, чем это грозит.

## 6. Проверки перед коммитом

```bash
./scripts/check.sh
```

`fmt`, `clippy -D warnings`, сборка workspace и без фич по умолчанию, тесты,
`cargo doc`. Правка кита проверяется его собственным `check.sh`.

## 7. Чек-лист

- [ ] файл лежит в крейте, которому ответственность принадлежит по §1
- [ ] `mod.rs` без логики
- [ ] публичные элементы документированы (`missing_docs` включён)
- [ ] ошибки разложены по вариантам, а не по строкам
- [ ] на пути соединения нет `unwrap` и `expect`
- [ ] правка кита аддитивна и записана в его `CHANGELOG.md`

## 8. Добавление протокола

Крейт в `protocols/`, зависимости по §1.1, и **четыре** правки: фича в
`crates/engine/Cargo.toml`, фича в `crates/daemon/Cargo.toml`, регистрация и
строка в `protocols_of` в `crates/engine/src/outbounds.rs`, форма в
`crates/gui/src/forms/protocol/`. Больше нигде трогать нечего: `outbounds.rs`
— единственное место, где протоколы перечислены.

### Чек-лист приёмки

- [ ] в `Cargo.toml` нет крейтов из `crates/`, кроме разрешённых §1.1
- [ ] в исходниках нет `std::net`, `tokio::net`, `std::process`
- [ ] `capabilities()` не врёт: `udp = false` у того, кто не возит датаграмм
- [ ] ошибки разложены по вариантам `ProtocolError`
- [ ] неверный пароль даёт `AuthRejected`, а не `Connect`; не умеет отличить —
      это записано в документе крейта
- [ ] есть тест разбора кадров на записанных байтах, без сети
- [ ] у рукопожатия есть срок (`penguin_transport::deadline`)
- [ ] `validate` ловит всё, что видно без сети: длину ключа, формат UUID,
      неизвестный метод, порт вне диапазона
- [ ] `Debug` не печатает пароль, ключ и UUID
- [ ] `close()` не оставляет живых задач
- [ ] расхождение часов, если протокол к нему чувствителен, названо в тексте
      ошибки
- [ ] форма говорит вслух то, что протокол делает небезопасно
- [ ] `./scripts/check.sh` проходит, `--no-default-features` собирается

### Откуда берётся формат

У большинства протоколов спецификации нет: формат — это то, что делает
эталонная реализация.

- **8.1.** Константа берётся из исходников эталона, а не по памяти. Не
  нашлось — работа останавливается, а не заполняется правдоподобным значением.
- **8.2.** Спецификация разошлась с кодом эталона — верим коду: по нему
  работает сервер, с которым надо сойтись.

Круговой прогон «зашифровали — расшифровали» проходит и когда всё сломано
одинаково в обе стороны. Он допустим рядом с внешним вектором, но не вместо;
где вектора нет — так и написано в тесте.

### Чего не будет

- **8.3.** Hysteria v1 — устарела по словам автора, Hysteria 2 уже есть.
- **8.4.** Lua и скриптуемые протоколы — исполнение чужого кода в процессе,
  который ходит в сеть с правами пользователя.
- **8.5.** Внешние плагины (`obfs-local`, `v2ray-plugin`) — `protocols/*` не
  запускает процессов. Что плагин делает транспортом, делается транспортом.

### Что не проверено

**Ни один чужой протокол не проверялся о живой сервер.** Проверены разбор на
записанных байтах и опубликованные тестовые векторы. Пока `scripts/interop` не
прогнан, «готово» означает «сходится с эталоном», а не «ходит».

Исключение — `pingwin`: он свой, эталона у него нет, зато есть сервер в этом
же дереве и проверка от края до края (`servers/pingwin/tests/roundtrip.rs`) на
настоящих сокетах.
