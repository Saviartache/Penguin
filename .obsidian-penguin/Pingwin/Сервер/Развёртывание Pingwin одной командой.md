# Развёртывание Pingwin одной командой

```bash
bash servers/pingwin/deploy.sh
```

Спрашивает: адрес сервера, доступ по SSH, доменное имя, порт.

Делает сам:

1. ставит Docker;
2. увозит исходники и собирает образ;
3. выписывает сертификат;
4. заводит ключи;
5. ставит продление в cron;
6. поднимает сервер и печатает [[Ссылка-приглашение|ссылку-приглашение]].

> [!tip] Идемпотентно
> Запускать можно сколько угодно раз: ключ и пароли не трогаются, ссылка та же.
> Так же и [[Обновление сервера Pingwin|обновляется]].
