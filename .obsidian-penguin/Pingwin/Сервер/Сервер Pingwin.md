# Сервер Pingwin

Один контейнер: сервер HTTP/3 на UDP и HTTP/2 на TCP ([[Pingwin]]). Прикрытие отдаёт сам
([[Прикрытие]]). Сертификат — Let's Encrypt через службу `certbot`, она
запускается только по требованию.

## Что нужно

- доменное имя, указывающее на сервер;
- открытый 80/tcp на время проверки имени;
- порт протокола — по умолчанию **443/udp и 443/tcp**: там браузеры ищут HTTP/3 и HTTP/2; по TCP приходят те, у кого режут UDP ([[Перенос по TCP]]).

## Устройство кода

| Файл `servers/pingwin/src/` | Что делает |
|---|---|
| `server.rs` | приём QUIC: опознанный — в relay, чужой — в cover |
| `connection.rs` | одно соединение: HTTP/3, [[Опознание]], запросы, датаграммы |
| `relay.rs` | [[Потоки]] и [[Датаграммы]] к цели, разрешение имён |
| `cover.rs` | [[Прикрытие]] |
| `policy.rs` | таблица пользователей: метка `user` → имя и пароль |
| `config.rs` | [[Настройки сервера Pingwin]] |
| `tls.rs` | [[Соединение]]: сертификат из PEM, ALPN `h3` |

Проверка от края до края на настоящих сокетах — `servers/pingwin/tests/roundtrip.rs`.
