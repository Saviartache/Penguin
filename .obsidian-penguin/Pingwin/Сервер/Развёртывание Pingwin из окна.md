# Развёртывание Pingwin из окна

«Добавить сервер» → Pingwin → **«Развернуть сервер»** (справа от «Сохранить»,
только у нового профиля). В окне: адрес, порт и пользователь SSH, пароль или
файл ключа (пусто — ключи и агент ssh), доменное имя, порт, почта для
Let's Encrypt, имя пользователя. По «Развернуть» видны шаги; в конце форма
профиля заполнена ссылкой — остаётся «Сохранить».

## Как устроено

```
окно ──stdin JSON──► penguin deploy pingwin --json ──► ssh … 'env PINGWIN_…=… bash -s'
     ◄──JSON строками──                            ◄── ::step/::ok/::link  ◄── install.sh
```

- В сеть окно не ходит (`AGENTS.md` §1.7): работу делает оно же в роли CLI.
- Запрос — на stdin, а не в аргументах: пароль не виден в списке процессов.
- Пароль SSH отдаётся через `SSH_ASKPASS`: им служит сам `penguin`, он
  печатает `PENGUIN_SSH_ASKPASS` и выходит. Нужен OpenSSH 8.4+
  (`SSH_ASKPASS_REQUIRE`).
- Исходники сервер качает сам: архив тега `v<версия клиента>` с GitHub —
  сервер собирается ровно той версии, что и клиент.
- Ключ хоста принимается при первом входе (`accept-new`), дальше проверяется.
- Не `root` — нужен `sudo` без пароля.
- «Отмена» во время работы убивает процесс; начатое на сервере доживает,
  повторный запуск продолжит с того же места.

> [!warning] Версия
> Тега текущей версии на GitHub ещё нет (сборка из дерева до выпуска) — шаг
> «Исходники» упадёт: развернуть такую сборку можно только `deploy.sh`.
