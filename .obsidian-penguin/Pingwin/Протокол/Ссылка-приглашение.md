# Ссылка-приглашение

```text
pingwin://<пароль>@<хост>:<порт>?key=<ключ>&sni=<имя>#<профиль>
```

| Часть | Правило |
|---|---|
| пароль, профиль | процентное экранирование всего, кроме букв, цифр и `-._~` |
| хост | IPv6 в квадратных скобках |
| порт | необязателен, по умолчанию 443 |
| `key` | открытый ключ сервера, `b64` ([[Ключи]]) |
| `sni` | необязательно: имя в сертификате, если не совпадает с хостом |

Собирает сервер (`pingwin-server link`, см. [[Профиль клиента Pingwin]]),
разбирает клиент. Общего кода нет (`AGENTS.md` §1): формат связан образцом —
одна строка в тесте на обеих сторонах.
