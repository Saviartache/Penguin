# Обозначения

- `X25519(a, B)` — RFC 7748, сырой результат.
- `Extract` / `Expand` — HKDF на SHA-256, RFC 5869.
- `Exporter(метка, контекст, длина)` — экспорт ключей TLS 1.3, RFC 8446, §7.5.
- `b64` — base64 для URL без дополнения (RFC 4648, §5).
- `‖` — склейка.

| Величина | Значение |
|---|---|
| метка выводов | `"pingwin"` |
| метка экспорта | `"EXPORTER-pingwin"`, контекст пустой, 32 байта |
| длина ключа | 32 байта |
| ALPN | `h3` |

Используется в [[Ключи]], [[Опознание]], [[Ссылка-приглашение]].
