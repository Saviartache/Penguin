# Ошибки Pingwin

| Что случилось | Что делает сторона |
|---|---|
| сертификат не проверился | клиент: обрыв, ошибка настроек |
| ответ на опознание не `204` или `pingwin-proof` не тот | клиент: отказ опознания |
| `CONNECT` до опознания | сервер: [[Прикрытие]] |
| цель недостижима | сервер: `502` с причиной — [[Потоки]] |
| не `2xx` на `CONNECT` | клиент: ошибка первого чтения, с причиной |
| датаграмма с Context ID не 0 или без адреса | получатель: отбрасывает — [[Датаграммы]] |

- Отказ опознания = не тот пароль **или** не тот ключ сервера. Отличить нельзя
  и не нужно: лечатся одинаково.
- Обрыв посреди рукопожатия — **не** отказ, а повод повторить попытку.
