# Прикрытие

Что видит тот, кого не узнали: на любой запрос неопознанного соединения сервер
отвечает как обычный сервер статических файлов.

| Запрос | Ответ |
|---|---|
| `GET`, `HEAD` существующего файла | `200`, файл |
| `GET`, `HEAD` каталога | его `index.html` |
| `GET`, `HEAD` чего-то другого | `404` |
| любой другой метод, включая `CONNECT` | `405` |

Не прошедшее проверку [[Опознание]] неотличимо от запроса без него.

Сайт прикрытия — `cover/html`, см. [[Файлы развёртывания Pingwin]].
