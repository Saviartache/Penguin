# Опознание

Первый запрос соединения, до любого `CONNECT`:

```
:method        GET
:scheme        https
:authority     <имя сервера>
:path          /
authorization  Pingwin b64(эфемерный клиента ‖ user ‖ client)
```

Токен — 72 байта до кодирования: 32 + 8 + 32 (см. [[Ключи]]).

## Проверка на сервере

1. Схема `Pingwin`, токен разбирается, длина 72.
2. `user` есть в таблице (`servers/pingwin/src/policy.rs`).
3. `client` совпадает с посчитанным — сравнение за постоянное время.

## Ответ

| Исход | Ответ |
|---|---|
| прошло | `204`, `pingwin-proof: b64(server)` |
| не прошло | как на `GET /` без заголовка — [[Прикрытие]] |

Клиент без `204` с верным `pingwin-proof` закрывает соединение — отказ
опознания ([[Ошибки Pingwin]]).

> [!important]
> Опознаётся **соединение**, а не запрос: дальше запросы идут без токена и
> только после `204`.
