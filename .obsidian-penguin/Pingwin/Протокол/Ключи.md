# Ключи

У сервера постоянная пара X25519: открытая половина — в профиле клиента,
закрытая — в [[Настройки сервера Pingwin|настройках сервера]]. У каждого
пользователя свой пароль.

```
exporter   = Exporter("EXPORTER-pingwin", "", 32)
ss         = X25519(эфемерный клиента, постоянный сервера)

user       = Expand(Extract(постоянный сервера, пароль), "pingwin user", 8)
prk        = Extract(exporter, ss ‖ пароль)
client     = Expand(prk, "pingwin client", 32)
server     = Expand(prk, "pingwin server", 32)
```

## Кто что может посчитать

| Величина | Знает только |
|---|---|
| `ss` | владелец закрытого ключа сервера |
| `exporter` | стороны этого соединения TLS |
| пароль | пользователь |

Сертификат доказывает имя, `server` — ключ: подмена требует обоих.

Примитивы — [[Обозначения]]; применение — [[Опознание]].
