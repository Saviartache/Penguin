# Pingwin

Прокси поверх HTTP/3 (RFC 9114). На проводе — обычный QUIC с сайтом: настоящий
TLS 1.3, настоящий сертификат, ALPN `h3`.

> [!info] Эталон
> `protocols/pingwin` и `servers/pingwin`. Разошлось с заметками — верен код.

## Свойства

| Свойство | Чем достигается |
|---|---|
| на проводе — обычный HTTP/3 | [[Соединение]] |
| сервер не подменить | сертификат **и** ключ X25519 — [[Ключи]] |
| пароль не перебрать по перехвату | вывод из X25519 и экспорта TLS — [[Ключи]] |
| повтор опознания бесполезен | экспорт TLS свой у соединения — [[Опознание]] |
| активная проверка бесполезна | [[Прикрытие]] |
| одно соединение на всё | [[Потоки]] и [[Датаграммы]] |

Нет: HTTP/1.1, HTTP/2, смены порта, 0-RTT, своего шифрования поверх QUIC.
