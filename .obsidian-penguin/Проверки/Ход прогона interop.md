# Ход прогона interop

1. **Сертификат** — самоподписанный для Hysteria 2, один раз (`tls/` в
   `.gitignore`).
2. **`docker compose up`** — [[Серверы interop]] и `target`: свой `nginx`,
   отвечающий `penguin-interop-ok`. Свой, а не сайт в сети: падение чужого
   сайта не должно выглядеть падением протокола.
3. **Профиль на протокол** и `penguin socks --no-rules`. Без `--no-rules`
   маршрутизация была бы лишней переменной.
4. **`curl --socks5-hostname`** до `target` **по имени**. Имя разрешает сервер
   на той стороне — это часть проверки: `target` есть только в сети `docker`.

> [!note]
> Настройки пишутся во временный каталог: профили запустившего не трогаются.
