# Interop

Тест на записанных байтах ловит ошибку в кадре, но не в понимании протокола:
свой разбор согласится сам с собой, и обе стороны будут одинаково неправы.
Поэтому клиент ходит через **чужие** серверы до своего веб-сервера.

```bash
./run.sh            # все протоколы
./run.sh socks5     # один
```

- Windows — `scripts\interop\run.cmd` из корня: сам найдёт `bash` из Git for Windows.
- Нужны `docker`, `openssl`, `curl`.
- Из `scripts/check.sh` не зовётся: образы тянутся долго, а падение сети
  выглядело бы падением коммита.
